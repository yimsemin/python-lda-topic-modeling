# 테스트 데이터 시나리오

## 00 생성·검수 기준

### 문서 목적

이 문서는 가상의 B2B SaaS 기업 재직자 1:1 반구조화 면담 응답을 생성하기 위한 기준문서이다. 생성 에이전트는 이 문서를 참고해 스프레드시트에 2026년 7~9월 면담 응답을 만든다.

### 재직자에게 질문

최근 회사의 조직·업무·평가 방식 변화와 관련해, 본인이 체감한 긍정적·부정적 경험은 무엇이며 그 경험이 일하는 방식이나 회사에 대한 생각에 어떤 영향을 주었나요?

### 탐침 방향

필요할 때만 업무방식, 협업, 평가 인식, 성장감, 잔류 의향에 미친 영향을 자연스럽게 포함한다.

### 출력 컬럼

| 항목 | 기준 |
| --- | --- |
| `date` | `date`는 2026년 7~9월 날짜를 `yyyy-mm-dd` 형식으로 입력한다. |
| `department` | `department`는 개발, 제품기획, 영업, 고객성공, 마케팅, HR, 재무, 경영기획, 정보보안 중 하나를 입력한다. |
| `role_level` | `role_level`은 사원, 대리, 과장, 차장, 팀장, 실장 중 하나를 입력한다. |
| `tenure_years` | `tenure_years`는 1 이상의 정수만 사용한다. |
| `intended_topic` | `intended_topic`은 1개만 입력한다. |
| `sub_topics` | `sub_topics`는 1~2개만 입력한다. 2개일 때는 세미콜론과 공백(`; `)으로 구분한다. |
| `article` | `article`에는 면담 응답 본문만 넣고 제목·번호·해설·질문문은 넣지 않는다. |

### 응답 문체

`article`은 실제 재직자 면담 발화를 읽기 좋게 정리한 서술체로 쓴다. 보고서체, 기사체, 컨설팅 문체, 과도한 구어체는 피한다. 각 응답에는 구체적 사건, 부서·직급 관점, 이해관계, 관계자와의 마찰이나 신뢰 변화 중 최소 2개가 드러나야 한다.

### 생성 절차

1. 면담월, 부서, 직급, 근속연수를 정한다.
2. 해당 월의 중심 사건과 누적 배경 사건을 고른다.
3. 주 토픽 1개와 보조 토픽 1~2개를 배정한다.
4. 응답자의 이해관계를 정한다.
5. 400~900자 `article`을 작성한다.
6. 토픽명 노출, 반복 표현을 검수한다.

### 피해야 할 패턴

- 핵심어를 LDA용으로 인위적으로 반복하지 않는다.
- 외부 경제 상황을 뉴스 요약처럼 쓰지 않는다.
- 실제 기업명, 실제 인물명, 실제 사건명을 쓰지 않는다.
- 모든 응답을 같은 서론-본론-제안 구조로 쓰지 않는다.
- 한 응답 안에서 중심 토픽이 흐려질 정도로 여러 이슈를 병렬 나열하지 않는다.

## 01 토픽 사전

### 운용 원칙

토픽명은 `intended_topic`과 `sub_topics` 컬럼에서만 사용한다. `article`에는 T번호나 토픽명을 직접 쓰지 않는다. 각 응답은 주 토픽 1개와 보조 토픽 1~2개로 설계한다.

### 토픽 목록

| 토픽 | 설명 |
| --- | --- |
| T01 조직방향성·전략정렬 | 회사의 목표, 우선순위, 전략 전환에 대한 이해와 혼선. |
| T02 변화관리·조직개편 | 조직개편, 제도 변경, 변화 수용·저항·피로. |
| T03 의사결정·역할명확성 | 결정권, 책임소재, 보고라인, 역할 경계의 불명확성. |
| T04 업무프로세스·운영효율 | 업무 절차, 중복 업무, 병목, 문서화, 인수인계 문제. |
| T05 리더십신뢰·관리방식 | 리더의 일관성, 설명 책임, 업무 배분, 관리 방식에 대한 신뢰. |
| T06 소통·정보공유 | 정보 공유의 시점, 정확성, 공식 메시지와 비공식 소문의 차이. |
| T07 협업·갈등관리 | 부서 간 우선순위 충돌, 조율 실패, 사일로, 핑퐁. |
| T08 업무부담·직무스트레스 | 업무량, 인력 부족, 긴급 대응, 심리적 압박. |
| T09 성과평가·보상공정성 | 평가 기준, 피드백, 성과급, 승진, 보상의 납득 가능성. |
| T10 성장·역량개발 | 커리어, 교육, 전문성, 역할 확장, 학습 기회. |
| T11 조직몰입·이직의도 | 잔류 의향, 조직 애착, 외부 기회 비교, 이직 고민. |
| T12 웰빙·지속가능성 | 소진, 회복 부족, 근무시간, 일생활균형, 지속 가능성. |

### 보조 단서

심리적안전감, 조직문화, 소속감, 자율성, 직무의미감, 온보딩, 고용안정감은 별도 토픽으로 과도하게 분리하지 않고 위 토픽에 섞어 사용한다.

## 02 배경·사건 흐름

### 회사 설정

| 구분 | 내용 |
| --- | --- |
| 기업 | 응답자가 재직 중인 기업은 서울 소재 B2B SaaS 기업이며 직원 규모는 약 850명이다. 고객은 중견·대기업의 영업, 고객지원, 운영관리 부서이다. |
| 조직 | 조직은 개발, 제품기획, 영업, 고객성공, 마케팅, HR, 재무, 경영기획, 정보보안으로 구성된다. |
| 핵심 갈등 | 핵심 갈등은 성장기 방식이 효율 중심 경영으로 전환되는 과정에서 생긴 역할, 평가, 협업, 업무부담 문제이다. |

### 누적 배경

| 연도 | 내용 |
| --- | --- |
| 2024년 | 대형 고객 확보와 채용 확대로 빠르게 성장했다. 자율성과 빠른 실행이 강점이었지만 역할 정의, 문서화, 온보딩, 인수인계는 충분히 정비되지 않았다. |
| 2025년 | 신규 고객 확보 속도가 둔화되고 기존 고객 유지와 업셀링이 중요해졌다. 조직은 커졌지만 목표 설정, 평가, 협업 프로세스, 의사결정 권한은 성장기 방식에 머물렀다. |
| 2026년 | 수익성, 고객 유지율, 운영 효율, 제품 안정성이 강조되면서 구성원은 통제 강화, 평가 압박, 성장 기회 축소를 체감한다. |

### 월별 사건

| 월별 사건 | 내용 |
| --- | --- |
| 1월: 수익성 중심 기조 | 성장률보다 수익성, 제품 완성도, 고객 유지율이 강조된다. |
| 2월: KPI 재설계 | 고객 유지율, 제품 안정성, 영업이익률 중심으로 KPI가 바뀐다. |
| 3월: 대형 고객 장애 | 시스템 장애와 데이터 연동 오류가 발생하고 책임소재와 고객 설명 방식의 갈등이 드러난다. |
| 4월: 로드맵 재조정 | 신규 기능 일부가 연기되고 안정성 개선에 리소스가 배정된다. |
| 5월: 비용 통제와 채용 동결 | 채용 동결, 외주비 절감, 교육비 축소가 발표된다. |
| 6월: AI 업무도구 도입 | 보고서, 상담 요약, 제안서, 회의록, 장애 리포트에 AI 도구 사용을 권장한다. |
| 7월: 고객 세그먼트 조직개편 | 제품 중심 조직에서 고객군 중심 조직으로 바뀌고 보고라인과 역할 범위 혼선이 커진다. |
| 8월: 성과평가와 보상 불만 | 상반기 평가와 하반기 목표 조정안이 공유되며 보이지 않는 업무의 인정 문제가 드러난다. |
| 9월: 핵심 인력 이탈 | 개발 리드, 고객성공 매니저, 영업 핵심 인력 일부가 퇴사하거나 이직 의사를 밝힌다. |

### 핵심 인과

- 전략 전환 -> KPI 재설계 -> 평가·보상 불만.
- 고객 장애 -> 책임소재 갈등 -> 협업 피로.
- 채용 동결 -> 업무부담 증가 -> 성장 기회 축소.
- 조직개편 -> 역할 혼선 -> 리더십 신뢰 약화.
- 핵심 인력 이탈 -> 업무 지속 가능성 우려 -> 이직 고민.

## 03 면담 설계

### 월별 초점

| 월 | 초점 |
| --- | --- |
| 7월 | 조직개편, 역할 혼선, 보고라인 변경, 소통 부족이 중심이다. |
| 8월 | 평가·보상, 목표 변경, 인정 부족, 리더십 설명 책임이 중심이다. |
| 9월 | 핵심 인력 이탈, 업무 지속 가능성, 소진, 이직 고민이 중심이다. |

| 제품기획 | 제품기획: 경영진 요구, 고객 요구, 개발 리소스 사이의 조정 부담. |

### 직급·근속 관점

| 구분 | 관점 |
| --- | --- |
| 저연차 | 저연차는 온보딩, 정보 접근성, 역할 학습, 커리어 불확실성을 말한다. |
| 중간연차 | 중간연차는 실무 책임 증가, 평가·보상 불만, 업무 부담, 이직 고민을 말한다. |
| 팀장·실장 | 팀장·실장은 위의 방향과 현장 불만 사이의 압박, 설명 책임, 평가자 역할 부담을 말한다. |
| 시니어·핵심 인력 | 시니어·핵심 인력은 오래 누적된 기술부채와 조직 문제, 외부 기회 비교, 잔류 조건을 말한다. |

### 시간 표현

면담 본문에서는 사건월을 직접 반복하지 않는다. “연초부터”, “조직개편 이후”, “상반기 평가가 나온 뒤”, “최근 핵심 인력이 나간 뒤”, “그때 이후”, “요즘 들어”와 같이 다소 추상적이고 간접적으로 표현한다.

### 발화 다양성

같은 사건을 다루더라도 부서, 직급, 근속연수, 이해관계, 감정 강도, 리더 신뢰 수준, 이직 의향을 바꾼다.

일부 응답은 변화의 필요성에 동의하거나 개선 기대를 유지한다. 모든 응답이 부정적으로만 흐르지 않게 한다.

“방향은 이해하지만”, “취지는 이해하지만”, “기준이 명확하지 않다”, “현장에서는 부담이 크다”, “평가에 반영되지 않았다”, “남은 사람이 버티는 구조다” 같은 표현은 반복하지 말고 상황에 맞게 변형한다.
